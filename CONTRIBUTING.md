# Contributing

Issues and pull requests are welcome. Small fixes with a test can go straight to a pull request. For anything larger, open an issue first so we can agree on the scope.

When reporting an import issue, attach the ZPL file and the expected result.

## Review

Every pull request is reviewed before merging. If there are suggestions, we work through them together. If you don't have time to follow up, the maintainer can also take it from there.

## Pull requests

- Include a regression test with every bug fix. The test should fail without the fix.
- Use `type(scope): what changes` for commit titles.

## AI

AI-assisted contributions are fine, provided you have reviewed and understood the code you submit. Please reply to review comments yourself.
